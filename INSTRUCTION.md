# How to run the app

## 1. Install Docker

Download and install Docker for your OS: https://docs.docker.com/get-docker/

## 2. Run the application

```
docker run -d -p 8000:8000 666phx/todoapp:latest
```

## 3. Open in browser

Go to: http://localhost:8000
