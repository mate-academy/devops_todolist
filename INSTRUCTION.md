# Deployment and Run Instructions for To-Do Application


🔗 **[Docker Hub Repository Link](https://hub.docker.com/repository/docker/bilyk143/todoapp/)**


###

1. **Pull the official image from Docker Hub:**

docker pull bilyk143/todoapp:1.0.0

2. **Run the container:**

docker run -p 8080:8080 bilyk143/todoapp:1.0.0

3. **Access the application:**

After the container is running, open your browser and navigate to:
- http://localhost:8080
- or http://0.0.0.0:8080

The To-Do application will be available at the above URLs.
