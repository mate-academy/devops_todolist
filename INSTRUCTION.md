# TodoApp Docker Instructions

## Overview

This repository contains a Django-based Todo application packaged in a Docker container. The following instructions will guide you through building and running the application in Docker.

## DockerHub Repository

The Docker image for this application is available on DockerHub at the following link:

[DockerHub - shum430/todoapp](https://hub.docker.com/repository/docker/shum430/todoapp/general)

## Requirements

- Docker must be installed on your machine.  
  You can follow the installation instructions for Docker from the official site: [Install Docker](https://docs.docker.com/get-docker/).

## Building the Docker Image

To build the Docker image locally, execute the following command in your terminal:

```bash
docker build -t yourname:yourtag .
```


## Running the Docker container

To run the Docker container, execute the following command in your terminal:

```bash
docker build -t yourname:yourtag .
```


## Now you can acccess your app in localhost at browser
http://localhost:8080
