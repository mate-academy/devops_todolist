The Docker image for the ToDo app is available at:
https://hub.docker.com/repository/docker/vladdemchuk1999/todoapp/general

Instructions for Building and Running the Container

Pull the pre-built image from Docker Hub:

`docker pull vladdemchuk1999/todoapp:1.0.0`
`docker run -p 8080:8080 vladdemchuk1999/todoapp:1.0.0`

Accessing the Application
	1.	Open your web browser.
	2.	Navigate to:
http://localhost:8080

The application will be accessible via this URL.
