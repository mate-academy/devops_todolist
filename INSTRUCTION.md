## 🔧 How to Build the Image Locally

1. git clone https://github.com/rootDebian/devops_todolist.git
2. Переходим в папку с проектом
3. docker build -t todoapp
4. docker run -p 8080:8080 todoapp .

Аппка доступна по адресу localhost:8080, 127.0.0.1:8080
