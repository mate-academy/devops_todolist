# ToDo App Docker Instructions

## Docker Hub Repository
The Docker image is available at: [lexm7/todoapp:1.0.0](https://hub.docker.com/r/lexm7/todoapp)

## To run the Docker container:
    ```bash
    docker run -p 8080:8080 lexm7/todoapp:1.0.0

## Building the Docker Image
   ```bash
   git clone <your-repo-url>
   cd <repo-name>

## Once the container is running, open your browser and navigate to:
    http://localhost:8080
    You can access the landing page or explore the API from there:
    http://localhost:8000/api/
